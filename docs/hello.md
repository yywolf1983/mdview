# 📖 欢迎使用 mdview

> 一个用 **Rust** + [axum](https://crates.io/crates/axum) + [pulldown-cmark](https://crates.io/crates/pulldown-cmark) 打造的本地 Markdown 文件浏览器与编辑器。
> 把任意文件夹变成一个可浏览、可编辑、可新建、可删除的轻量 Markdown Wiki。

---

## ✨ 功能一览

| 类别 | 能力 |
|:-----|:-----|
| 🌐 浏览 | 递归列出目录下的所有 `.md` 文件，目录 / 文件用彩色图标区分，支持面包屑导航 |
| 🎨 渲染 | GitHub 风格 HTML 输出，完美支持表格 / 删除线 / 任务列表 / 标题锚点 |
| ✏️ 编辑 | 每个 MD 页内置 IDE 风格源码编辑器，一键保存 |
| ➕ 新建 | 一键新建 `.md` 文件或子目录（文件名自动补后缀） |
| 🗑 删除 | 安全删除文件或**空**目录，带风格化二次确认弹窗 |
| 🔗 超链接 | 站内 `.md` 相对链接自动映射；图片 / 附件通过 `/static/` 路由加载 |
| 🛡 安全 | 所有路径 canonicalize 校验，禁止 `../` 目录遍历越权 |
| 📱 响应式 | 桌面 / 平板 / 手机自适应显示 |

---

## 🚀 快速启动

```bash
# 编译运行（默认指向 ./docs）
cargo run

# 指定目录与监听地址
cargo run -- --dir /path/to/notes --addr 0.0.0.0:8080

# 发布版本构建
cargo build --release
./target/release/mdview --dir ~/note
```

打开浏览器访问 `http://127.0.0.1:3000` 即可。

## 🖱 使用场景速览

### 1. 浏览文件
首页或任意目录页会列出所有子目录与 Markdown 文件，**hover 会高亮**，点击即可进入：
- 📁 **黄色图标**：子目录
- 📄 **蓝色图标**：Markdown 文件
- 末尾「原始」查看源码 / 「删除」安全移除

### 2. 编辑文档
在任意 `.md` 详情页顶部点击 **✎ 编辑**：
- 编辑器左侧自带 IDE 风格灰条（仿行号区）
- 聚焦时紫色发光边框提示
- 修改后点击 **💾 保存** 立即写回磁盘

### 3. 新建内容
每个目录页顶部的表单：
```
[ 输入文件或目录名 (自动追加 .md) ]  [☑ 目录]  [＋ 新建]
```
> 例如输入 `weekly/plan`（勾上"目录"）会创建 `weekly/plan/` 目录；
> 输入 `周报-0819` 会创建 `周报-0819.md` 并填入 `# ` 模板。

### 4. 文档内互相跳转
在 hello.md 同目录下，像下面这样写即可**站内跳转**到 demo.md：
```markdown
- [Markdown 完整语法演示](./demo.md)
```

## 🎯 推荐用法

- **个人知识库**：把 `~/notes` 设为根目录，全家桶的本地 Wiki
- **项目文档预览**：`mdview --dir ./docs` 让团队成员在本地打开预览
- **笔记整理**：配合新建/删除/编辑，随时整理归档
